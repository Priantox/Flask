<h2>🚀 Flask Setup Guide</h2>

<h3>📌 Create a Virtual Environment</h3>
<ul>
  <li><code>python -m venv venv</code></li>
</ul>

<h3>📌 Activate the Virtual Environment</h3>
<ul>
  <li><strong>Windows:</strong> <code>venv\Scripts\activate  (venv can be another name)</code></li>
</ul>

<h3>📌 Install Flask</h3>
<ul>
  <li><code>pip install flask</code></li>
</ul>

<h3>📌 Install Flask-SQLAlchemy</h3>
<ul>
  <li><code>pip install flask-sqlalchemy</code></li>
</ul>

<h3>📝 Verify Installation</h3>
<ul>
  <li><code>pip freeze</code> (You should see <strong>Flask</strong> and <strong>Flask-SQLAlchemy</strong> listed)</li>
</ul>

<h3>To Run Code</h3>
<ul>
  <li><code>python3 app.py(Name of the folder)</code></li>
</ul>
